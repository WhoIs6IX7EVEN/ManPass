# ManPass — инструкция

1. Запустите **ManPass.exe**. При первом открытии создайте длинный уникальный мастер-пароль.
2. Добавляйте записи через «Добавить»: сервис, сайт, логин, пароль, категория, 2FA, примечания.
3. В профиле можно сохранить имя, почту, телефон, сделать резервную копию и изменить мастер-пароль.
4. Для резервного копирования используйте команду приложения. Скопируйте зашифрованную копию в отдельное надёжное место.
5. Команда «Заблокировать» очищает доступ к хранилищу в текущей сессии; для нового входа потребуется мастер-пароль.
6. Закрытие окна может скрывать программу в трее; для полного завершения воспользуйтесь «Выход» в меню трея.

**Осторожно:** не теряйте мастер-пароль и не запускайте разные копии приложения на одной базе. Не храните единственную копию важных паролей в непроверенной программе. Сама SQLite-база и резервные копии содержат зашифрованные данные, но логика приложения не проходила независимого аудита.
