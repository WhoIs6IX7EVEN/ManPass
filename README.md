# ManPass

### Secure. Simple. Personal.

**ManPass** — бесплатный локальный менеджер паролей для Windows, созданный на Python и Flet.

Храните пароли, логины и данные учётных записей в одном зашифрованном хранилище. Управляйте ими через современный интерфейс, быстро находите нужные записи и создавайте надёжные пароли.

## Возможности

### Управление паролями

- Добавление, редактирование и удаление учётных записей.
- Сохранение названий сервисов, логинов, паролей и URL.
- Быстрое копирование логинов и других данных.
- Поиск по сохранённым аккаунтам.
- Организация записей по категориям.
- Добавление аккаунтов в избранное.
- Хранение заметок.
- Отметка о включённой двухфакторной аутентификации (2FA).

### Безопасность

- Шифрование записей с помощью **AES-256-GCM**.
- Получение ключа из мастер-пароля через **Argon2id**.
- Локальное хранение данных в **SQLite**.
- Защита хранилища мастер-паролем.
- Автоматическая блокировка при бездействии.
- Возможность смены мастер-пароля.
- Создание резервных копий.

### Дополнительные возможности

- Генератор случайных паролей.
- Работа в системном трее Windows.
- Восстановление окна приложения через ярлык.
- Профиль пользователя с контактными данными.
- Проверка обновлений через GitHub Releases.
- Уведомление о новых стабильных версиях.

> Отметка 2FA является информационной и не включает двухфакторную аутентификацию на сторонних сервисах.

## Установка

1. Перейдите на страницу [GitHub Releases](https://github.com/WhoIs6IX7EVEN/ManPass/releases).
2. Скачайте `ManPass-Setup.zip`.
3. Распакуйте архив.
4. Запустите находящийся внутри установщик.
5. Ознакомьтесь с пользовательским соглашением.
6. Завершите установку и откройте ManPass.

При первом запуске создайте мастер-пароль для защиты нового хранилища.

**Важно:** не забывайте мастер-пароль. Без него восстановление доступа к зашифрованным данным может оказаться невозможным.

## Где хранятся данные?

По умолчанию ManPass использует папку:

`%USERPROFILE%\PasswordVault\`

Основной файл хранилища:

`vault.db`

Расположение базы данных можно изменить в настройках приложения.

Данные хранятся отдельно от папки установленной программы. Это позволяет обновлять ManPass без намеренного удаления хранилища.

**Рекомендуется регулярно создавать резервные копии и хранить их в безопасном месте.**

## Обновления

ManPass поддерживает проверку новых стабильных версий через GitHub Releases.

Когда становится доступна новая версия, приложение может показать уведомление и предложить перейти на страницу скачивания.

В новых версиях индикатор доступного обновления также отображается в нижней части боковой панели.

**Автоматическая установка обновлений пока не реализована.** Пользователь скачивает и устанавливает новую версию самостоятельно.

Для обновления:

1. Создайте резервную копию хранилища.
2. Полностью закройте ManPass через системный трей.
3. Скачайте новый установщик.
4. Запустите его поверх существующей установки.

Не удаляйте базу данных ради обновления приложения.

## Запуск из исходного кода

Клонируйте репозиторий:

```powershell
git clone https://github.com/WhoIs6IX7EVEN/ManPass.git
cd ManPass
```

Создайте виртуальное окружение:

```powershell
py -3.12 -m venv .venv
```

Установите зависимости:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите приложение:

```powershell
.\.venv\Scripts\python.exe app\main.py
```

## Сборка Windows

Для создания portable-версии:

```powershell
.\scripts\build_windows.ps1
```

После успешной сборки программа находится по пути:

`dist\ManPass\ManPass.exe`

Для создания установщика предварительно установите Inno Setup 6, затем выполните:

```powershell
.\scripts\build_installer.ps1
```

Результат:

`dist\installer\ManPass-Setup.exe`

Сборку также можно запустить автоматически через **GitHub Actions → Windows Desktop Release**.

## Безопасность и ограничения

ManPass разрабатывается как локальный менеджер паролей. Приложение не выполняет облачную синхронизацию пользовательского хранилища. Проверка обновлений обращается к GitHub, но не отправляет туда содержимое базы паролей.

**Проект пока не проходил независимый аудит безопасности.**

Шифрование AES-256-GCM и использование Argon2id сами по себе не гарантируют отсутствие уязвимостей в приложении.

В частности, необходима дальнейшая проверка защиты секретов в оперативной памяти, поведения при блокировке Windows, работы системного трея, обработки ошибок и безопасности установщика.

Не рекомендуется использовать ManPass как единственное место хранения критически важных паролей до завершения дополнительного тестирования.
