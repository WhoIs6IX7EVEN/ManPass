# ManPass

**ManPass — локальный менеджер паролей для Windows.**

Приложение помогает хранить и организовывать учётные данные в зашифрованном SQLite-хранилище, защищённом мастер-паролем.

Разработчик: **6IX7EVEN**

**Текущая версия:** 3.6.1

## Возможности

- Хранение названий сервисов, логинов, паролей и адресов сайтов.
- Копирование учётных данных.
- Поиск по сохранённым аккаунтам.
- Категории и избранные записи.
- Генератор случайных паролей.
- Учёт включённой двухфакторной аутентификации (2FA).
- Сохранение заметок.
- Локальное шифрование данных с использованием AES-256-GCM.
- Получение ключа из мастер-пароля с помощью Argon2id.
- Создание резервных копий SQLite.
- Смена мастер-пароля.
- Работа через системный трей Windows.
- Уведомления о новых стабильных версиях через GitHub Releases.

> **Примечание:** отметка 2FA предназначена для учёта и не включает двухфакторную аутентификацию на сторонних сайтах.

| ManPass Portable | Запуск без установки |

## Установка

1. Скачайте установщик из GitHub Releases.
2. Запустите установку.
3. Ознакомьтесь с пользовательским соглашением.
4. Завершите установку.
5. Запустите ManPass.
6. При первом запуске создайте надёжный мастер-пароль.

**Внимание:** потеря мастер-пароля может сделать расшифровку хранилища невозможной. Храните его в безопасном месте.

## Обновления

ManPass поддерживает проверку стабильных версий через GitHub Releases.

Если опубликована новая версия, приложение может сообщить о доступном обновлении и предложить открыть страницу релиза.

Обновление устанавливается пользователем вручную. Перед обновлением рекомендуется создать резервную копию хранилища.

## Безопасность

ManPass использует следующие технологии:

- **AES-256-GCM** — аутентифицированное шифрование записей.
- **Argon2id** — получение криптографического ключа из мастер-пароля.
- **SQLite** — локальное хранение зашифрованных данных.

ManPass не отправляет содержимое хранилища в облако. Сетевая проверка обновлений обращается к GitHub.

**Ограничения:** проект находится в разработке и не проходил независимый аудит безопасности. Он не гарантирует защиту от вредоносного ПО, компрометации операционной системы или извлечения секретов из памяти работающего приложения.

До завершения дополнительного тестирования не рекомендуется использовать ManPass как единственное место хранения критически важных паролей.

## Запуск из исходного кода

Требуется Python 3.12.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\main.py
```
