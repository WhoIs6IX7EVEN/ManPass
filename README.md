# ManPass — Desktop Release Candidate

**ManPass** — локальный менеджер паролей на Python / Flet. Эта репозитория содержит **кандидат на сборку**, а не проверенный публичный релиз. Не распространяйте приложение для хранения критически важных паролей без дополнительных проверок безопасности и тестов на Windows.

## Что внутри

- `app/main.py` — программа ManPass 3.5.1 (сохранена криптографическая совместимость со старой базой)
- `assets/manpass.ico` — значок Windows
- `scripts/build_windows.ps1` — тесты + portable-сборка
- `scripts/build_installer.ps1` — установщик через Inno Setup 6
- `installer/ManPass.iss` — сценарий установщика для пользователя, без прав администратора
- `tests/` — проверки криптографии / SQLite, без настоящих данных
- `.github/workflows/windows.yml` — сборка Windows в GitHub Actions по тегу/вручную

## Запуск для разработки

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\main.py
```

## Portable-сборка (Windows)

```powershell
.\scripts\build_windows.ps1
```

Итоги: `dist/ManPass/ManPass.exe` и `ManPass-Portable.zip`. **Отправляйте ZIP, а не только .exe**, поскольку `.exe` требует файлов своей папки.

## Установщик (Windows)

Установите Inno Setup 6, затем:

```powershell
.\scripts\build_installer.ps1
```

Результат: `dist/installer/ManPass-Setup.exe`.

## GitHub

1. Создайте **пустой** репозиторий и загрузите *только* содержимое этого проекта.
2. Проверьте `git status` и `git diff --cached --name-only` — там не должно быть `vault.db`, `manpass_config.json`, backup-файлов, токенов или пользовательских данных.
3. Сделайте приватный репозиторий на период тестирования.
4. Запустите Workflow **Windows Desktop Release** через **Actions → Run workflow**; получите portable и installer как build artifacts.
5. Публикуйте GitHub Release только после тестирования на чистой Windows и проверки подписи/SmartScreen. Воркфлоу **не публикует** релиз автоматически.

## Хранилище

Текущая реализация хранит SQLite в домашней папке `PasswordVault` или по указанному пользователем пути. Она **не хранится внутри `dist` или установочной папки**. Удаление программы не должно удалять пользовательскую базу.

## Риски и условия публичного релиза

Нужны проверки: вход/выход, тайм-аут и блокировка Windows, диалоги, трей, выключение/сон, перенос БД, чтение резервных копий, обновление поверх старой установки, защита секретов в UI и в памяти, несколько тысяч записей, антивирус/SmartScreen, кодовая подпись. CLI-тесты **не заменяют** независимый аудит.

**Лицензия:** не задана. До выбора лицензии исходный код не разрешён автоматически к свободному переиспользованию. Для open-source варианта можно добавить MIT/Apache-2.0 после выбора правообладателя.

## Исправления 3.5.1
